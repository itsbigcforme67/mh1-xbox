# MH2 layouts of the smaller work structs, for tools/mh2_structs.py gen: writes include/mh2_layouts.h.
#   STRUCT NAME SIZE MACRO     MACRO(o): the MH2 offset of a byte written as an MH1 (or G) offset, for C that uses raw numbers
#   OLD NEW DECL ; TAG note    one field; OLD = 0x... MH1/G offset, - for a field MH1 and G do not have
# TAG says how the place is known:
#   code   read from MH2's code with the twin function's order or a vote from aligned code

#   guess  no place in MH2 was found. The field sits in a stretch no code touches, so C compiles; it is NOT MH2's real place
#
